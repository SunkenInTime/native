fix: **A retained widget tree no longer reads the app's build memory**: the runtime now copies each widget's placeholder text and immediate commands (with their polyline points, icon path elements, gradient stops, and mesh patches) into the view's own storage, as it already did for text and labels. A `UiApp` rebuild that failed after handing its tree to the runtime (for example when the platform focus service errored during autofocus) used to leave the runtime pointing into memory the next rebuild reused, and that next rebuild crashed comparing the two trees. The new per-view pools are budgeted in `canvas_limits` (`max_canvas_widget_immediate_commands_per_view` and friends), refuse an oversized layout atomically, and log the budget, its limit, and what to change.
- **Unchanged gradients and polylines stop repainting**: rebuild diffs compare polyline points, gradient stops, and mesh patches by value instead of by address, so an identical tree built in new memory no longer marks those widgets dirty.
