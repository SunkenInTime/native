fix: **Drive visible macOS GPU surfaces from their display clock**: armed surfaces now consume `CVDisplayLink` ticks from the window's active screen and retarget when the window moves between displays. Idle surfaces stop the clock, while occluded surfaces retain the existing low-rate heartbeat instead of waking at display rate. The pre-first-present and host fallbacks now derive their interval from the active screen rather than assuming 60 Hz. Embedders can explicitly request the next GPU-surface frame when an animation produces the same retained command bytes twice.
