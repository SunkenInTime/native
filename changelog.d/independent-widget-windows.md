feature: **Independent declared windows**: `UiApp` can host many windows that each render an independent part of the model (one per desktop widget): `window_view_revision` rebuilds only the windows whose inputs moved and projects the rest through `project_update`, `window_sync`/`window_on_frame` route by window label, a failing window keeps its last tree without stalling the others, and `WindowDescriptor` takes the widget surface flags (`transparent`, `layer`, `click_through`, `no_activate`, `gpu_backend`).
- **Widget host capacity**: `-Dwidget-windows=N` raises the widget profile's window and view capacity; the UiApp window budget, fx timer table, and image/font registries scale with it, and registered image/font storage is now allocated per registration (freed by `Runtime.deinit`).
